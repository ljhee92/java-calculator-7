# java-calculator-precourse
## 문자열 덧셈 계산기
* 입력한 문자열에서 숫자를 추출하여 더하는 계산기

## 기능 목록
1. 기본 구분자
- [ ] 쉼표(,) 또는 콜론(:)을 구분자로 가지는 문자열을 전달
- [ ] 구분자를 기준으로 숫자를 분리
- [ ] 분리한 각 숫자의 합을 반환

2. 커스텀 구분자
- [ ] 문자열 앞부분의 ``//``와 ``\n`` 사이에 위치하는 문자를 커스텀 구분자로 사용

3. 예외 처리
- [ ] 사용자가 잘못된 값을 입력할 경우 ``IllegalArgumentException`` 발생 후 종료

4. 입력
- [ ] 구분자와 양수로 된 문자열

5. 출력
- [ ] 덧셈 결과

6. 실행 결과 예시
```
덧셈할 문자열을 입력해 주세요.
1,2:3
결과 : 6
```

## 테스트 목록
1. 기본 구분자
- [x] 쉼표(,) 또는 콜론(:)을 가지고 있는 문자열인지 확인한다.
- [x] 쉼표(,) 또는 콜론(:)을 기준으로 문자열을 구분하여 숫자로 반환하는지 확인한다.
- [x] 쉼표(,)와 콜론(:)을 기준으로 구분하여 반환한 문자열을 모두 더한 값과 기대값이 동일한지 확인한다.

2. 커스텀 구분자
- [x] 문자열 앞부분에 ``//``와 ``\n``을 가지고 있는지 확인한다.
- [x] ``//``와 ``\n`` 사이에 커스텀 구분자가 있는지 확인한다.
- [x] ``//``와 ``\n`` 이후에 구분자가 있는지 확인한다.
- [x] 커스텀 구분자를 기준으로 문자열을 구분하여 반환하는지 확인한다.
- [x] 커스텀 구분자를 기준으로 구분하여 반환한 문자열이 숫자인지 확인한다.
- [x] 커스텀 구분자를 기준으로 구분하여 반환한 문자열을 모두 더한 값과 기대값이 동일한지 확인한다.

3. 예외 처리
- [ ] 사용자가 잘못된 값을 입력하면 ``IllegalArgumentException`` 예외를 던진 후 종료하는지 확인한다.
